# Visualizador_Jornada

Projeto desenvolvido em HTML e CSS para organizar e apresentar os trabalhos de tecnologia realizados por alunos de três turmas.

Funcionalidades

Organização dos projetos por turma.

Páginas individuais com descrições, imagens e integrantes.

Navegação entre páginas por links HTML.

Disponibilização de arquivos Scratch (.sb3).

Layout responsivo para computadores e celulares.

Tecnologias

HTML5: estrutura e navegação.

CSS3: estilização e responsividade.

Scratch: desenvolvimento dos projetos de programação visual.

Como executar

Baixe ou clone o repositório.

Mantenha os arquivos e as pastas organizados.

Abra o index.html no navegador.

O projeto não utiliza JavaScript nem exige instalação de dependências.
